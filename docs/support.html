Reply with ChatGPT

A personal Outlook add-in that helps you draft replies with ChatGPT, using your own ChatGPT login.

  1. Select an email and click Reply with ChatGPT in the toolbar.
  2. Pick a tone and click Copy prompt & open ChatGPT.
  3. Paste the prompt into ChatGPT (⌘V), then copy its answer.
  4. Paste the answer into the panel and click Create reply draft.
  5. Review the draft in Outlook and send it yourself.

The add-in is static files only. It makes no API calls, collects nothing, and never sends email.
